# 简历工坊 · Windows 发布

本仓库只存放简历工坊桌面版的安装包，源码与网页版在 [my-portfolio](https://director-code-c.github.io/my-portfolio/resume-workshop/) 中提供在线体验。

## 下载
到 [Releases](https://github.com/Director-code-c/resume-workshop-releases/releases) 下载最新版 简历工坊-<版本>-win-x64-Setup.exe，双击安装即可（Windows x64，按用户安装，无需管理员权限）。

未做代码签名，首次运行如遇 SmartScreen 提示，选择「仍要运行」。
